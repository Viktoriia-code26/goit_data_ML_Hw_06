# goit_data_ML_Hw_06

# Кластеризація методом K-means

## Опис
У роботі виконано кластеризацію двох наборів даних за допомогою алгоритму **K-means**:
- двовимірного датасету (`data_2d.csv`);
- датасету рукописних цифр **MNIST** (`mnist.csv`).

Для визначення оптимальної кількості кластерів використано **ліктьовий метод**. Для візуалізації результатів кластеризації датасету MNIST застосовано алгоритм **PCA**, який зменшує розмірність даних до двох головних компонент.

## Використані бібліотеки
- Python 3
- pandas
- numpy
- matplotlib
- scikit-learn

## Результати
- Завантажено та оброблено обидва датасети.
- Виконано кластеризацію методом K-means.
- Оптимальну кількість кластерів визначено за допомогою ліктьового методу.
- Для MNIST виконано зменшення розмірності методом PCA та побудовано візуалізацію кластерів.

## Висновок
Алгоритм K-means успішно виконав кластеризацію обох наборів даних. Для двовимірного датасету отримано чітко відокремлені кластери. Для датасету MNIST після застосування PCA вдалося візуалізувати результати кластеризації, хоча між окремими кластерами спостерігається часткове перекриття через схожість рукописних цифр та втрату частини інформації під час зменшення розмірності.
